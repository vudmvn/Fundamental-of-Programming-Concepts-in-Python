## 📌 2. Course Overview & Learning Objectives

The course **Fundamental Programming Concepts in Python (DSAI1003)** is a compulsory foundational course that establishes systematic computational thinking, structured program organization, and algorithmic problem-solving abilities using Python.

### 🎯 Course Objectives (COs):
- **G1 (Algorithmic Mindset):** Express algorithms using pseudocode and flowcharts; implement console and basic GUI programs to solve business problems.
- **G2 (Control Structures):** Master branching decision structures (`if-elif-else`) and loop structures (`while`, `for`) for repetitive tasks.
- **G3 (Modular Functions):** Design and implement modular and recursive functions for divide-and-conquer problem decomposition.
- **G4 (Built-in Collections):** Proficiently utilize and manipulate built-in collections (List, Tuple, Set, Dictionary).
- **G5 (File I/O & Exceptions):** Perform persistent text/binary file operations and build robust exception-handling schemes (`try-except`).
- **G6 (Object-Oriented Programming):** Master and apply core OOP principles (Classes, Objects, Encapsulation, Inheritance, Polymorphism).
- **G7 (Self-Study & Team Productivity):** Develop lifelong self-study habits, independent problem solving, collaboration skills, and personal responsibility.

## ⚖️ 5. Course Assessment Scheme

* **Homework Assignments (HW - 30%):** Minimum 4 sets of theoretical and practical programming assignments submitted via LMS/Moodle (bi-weekly).
* **Midterm Examination (30%):** Written test or lab computer exam covering Lessons 1 through 6 in Week 7.
* **Final Examination (40%):** Comprehensive practical programming examination conducted on lab computers in Week 15.
* **Passing Requirement:** Final weighted grade $\ge$ **5.0 / 10.0**; minimum class attendance of **80%**.
