## 3. Course Description

This course is an introduction to computer programming using Python that focuses on the essentials—and on effective learning. It is designed to serve a wide range of student interests and abilities; it is suitable for a first course in programming for data science, computer science, engineering, and relevant disciplines. No prior programming experience is required, and only a modest amount of high school algebra is needed.

The students will start from basic algorithmic design concepts and presentation using pseudocode and flowcharts. Then, students will learn to develop simple console and graphical user interface applications using various core programming concepts (variables, arrays, decision making, branches, functions). Students will be introduced to file processing techniques and the concept of exceptions. Finally, students will be introduced to the concept of Object-Oriented Programming (OOP). Applications and case studies in business and economics will be introduced throughout the course to sharpen students' skills and to guide students with practical applications.
