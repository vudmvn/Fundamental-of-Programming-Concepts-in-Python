2. Programming Exercises

Mỗi bài có mô tả, mã khởi tạo, gợi ý và nhiều kiểm thử. Chạy Python trực tiếp trên trình duyệt.

Nguyên tắc chấm: Review chấm theo đáp án/mô hình đề xuất. Programming kiểm thử bằng Python thật, không chấm qua từ khóa hoặc khớp chuỗi code.
Lưu ý khi triển khai: Khối trắc nghiệm hoạt động offline. Để chạy Python trong HTML, trình duyệt cần tải Pyodide qua Internet lần đầu; không gửi bài làm lên server. Nếu không có mạng, dùng tệp grade_local.py trong ZIP để chấm bằng Python cài trên máy. Kết quả lưu ở trình duyệt này, không phải hệ thống điểm chính thức.
