Mức 4 · Hoàn thiện chương trình Python

Cơ chế tự chấm: các bài code chạy Python thực bằng Pyodide trong một Web Worker với test case. Lần đầu cần kết nối Internet để tải trình Python; sau đó sẽ dùng bộ nhớ đệm của trình duyệt nếu có.
